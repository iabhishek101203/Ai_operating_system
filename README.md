# AI Operating System Assistant

Research project focused on building a secure AI-powered Operating System Assistant using LLM function calling, FastAPI, React, and safe tool execution.

The core principle is safety: the assistant must never execute arbitrary shell commands generated by an LLM. Natural language requests are converted into structured intents, validated, previewed, confirmed by the user, executed through safe Python tools, logged, and made recoverable where possible.

## Safety Pipeline

```text
Natural Language
-> Intent Understanding
-> LLM Function Calling
-> Structured JSON
-> Validation
-> Preview
-> User Confirmation
-> Safe Python Tool Execution
-> Operation Logging
-> Undo Support
```

## Repository Layout

```text
backend/   FastAPI backend, validation, tool execution, operation history
docs/      Architecture, safety model, and research notes
frontend/  Future React + TypeScript interface
```

## Current Milestone

Milestone 1 builds the backend safety foundation with one low-risk operation: safe file search. This proves the validation, preview, execution, and logging flow before adding Gemini or a full UI.
