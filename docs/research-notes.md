# Research Notes

## Inspiration

- NaSh: Guardrails for an LLM-Powered Natural Language Shell
- AIOS: LLM Agent Operating System
- AGrail
- Access Control in LLM Agent Systems

## Practical Direction

This project is not trying to reproduce any one paper exactly. The goal is a practical, secure, explainable assistant that applies research ideas to real operating system workflows.

## Research Questions

- How can natural language OS actions be represented as safe, auditable structured intents?
- What validation boundaries are required before an LLM-assisted system can modify files?
- How should previews communicate risk and expected effects to users?
- What undo metadata is necessary for recoverability?
- How can access control be designed for local AI agents?
